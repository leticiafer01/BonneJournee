# BONNE JOURNÉE

**Photographic Journal — Web Project**

---

## Overview

**Bonne Journée** is a front-end web project focused on building an editorial-style photography journal. The goal is to translate print-inspired visual design into a clean, performant, and responsive web experience.

The project emphasizes layout, typography, and interaction over heavy frameworks, prioritizing clarity and maintainability.

---

## Objectives

* Create an editorial photographic layout inspired by independent journals
* Implement a masonry-style image gallery using pure CSS
* Develop a minimal, accessible modal for image visualization
* Maintain a lightweight front-end with no external dependencies

---

## Features

* Responsive masonry gallery using CSS columns
* Fullscreen image modal with JavaScript
* Clean and minimal navigation
* Mobile-first responsive adjustments
* Semantic HTML structure

---

## Technologies & Tools

* **HTML5** — semantic structure
* **CSS3** — layout, responsive design, visual identity
* **JavaScript (Vanilla)** — modal interaction
* **Git & GitHub** — version control

No frameworks or external libraries are used.

---

## Design & UX Decisions

* Typography relies on system fonts to ensure performance and consistency
* High whitespace usage to improve visual hierarchy
* Images are treated as primary content; UI elements remain secondary
* Modal behavior avoids external plugins for better control and simplicity

---
